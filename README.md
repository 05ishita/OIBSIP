# NOVA — Work Smarter. Create Faster.

A modern, responsive landing page for NOVA, a fictional AI-powered productivity platform designed to help teams work smarter, stay organized, and create faster.

## 🚀 Features

- Sticky responsive navigation bar
- Hero section with clear CTA buttons
- Product dashboard preview
- Feature showcase section
- How It Works workflow section
- About section with statistics
- Call-to-action section
- Responsive footer with navigation links
- Fully responsive design for desktop, tablet, and mobile
- Consistent modern colour palette and typography
- CSS Grid and Flexbox based layout
- Smooth scrolling navigation

## 🛠️ Technologies Used

- HTML5
- CSS3
- CSS Flexbox
- CSS Grid
- Google Fonts

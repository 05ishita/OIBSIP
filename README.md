## 🚀 Projects

### 1. Landing Page
A modern and responsive landing page designed using semantic HTML and CSS with a sticky navigation bar, hero section, feature sections, CTA and responsive layouts.

**Folder:** `WebDev-L1-LandingPage`

---

### 2. Personal Portfolio
A professional responsive portfolio website showcasing profile information, skills, projects and contact details.

**Folder:** `WebDev-L1-Portfolio`

---

### 3. Temperature Converter
A responsive temperature conversion application supporting Celsius, Fahrenheit and Kelvin with input validation and absolute-zero validation.

**Folder:** `WebDev-L1-TemperatureConverter`

---

### 4. Calculator
A functional calculator supporting arithmetic operations, decimal values, operator chaining, clear, backspace and keyboard input.

**Folder:** `WebDev-L2-Calculator`

---

### 5. Tribute Page
A responsive tribute webpage dedicated to Dr. A.P.J. Abdul Kalam featuring his achievements, timeline, inspirational quote and biography.

**Folder:** `WebDev-L2-TributePage`

---

### 6. To-Do List
A task management application with pending and completed tasks, inline editing, deletion, task counters, timestamps and LocalStorage persistence.

**Folder:** `WebDev-L2-ToDo`

---

### 7. Login Authentication
A front-end authentication system featuring registration, login, password validation, duplicate account checking, protected dashboard and logout functionality.

**Folder:** `WebDev-L2-LoginAuthentication`

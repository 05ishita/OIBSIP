# Dr. A.P.J. Abdul Kalam — Tribute Page

A responsive tribute webpage dedicated to Dr. A.P.J. Abdul Kalam, one of India's most respected scientists, educators and public figures.

The webpage presents his journey, achievements, values and lasting influence through a modern editorial-style design.

## Features

- Hero section with title and tagline
- Prominent visual portrait area
- Original tribute content
- Biography section
- Career timeline
- Major achievements
- Inspirational quote section
- Legacy section
- Responsive design
- Multiple background colours
- Multiple typography styles
- Smooth scrolling
- Mobile-friendly layout

## Technologies Used

- HTML5
- CSS3
- CSS Grid
- CSS Flexbox
- Google Fonts
- Responsive Web Design

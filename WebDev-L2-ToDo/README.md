# FocusList — To-Do List Application

FocusList is a responsive task management web application created for the Oasis Infobyte Web Development and Designing Internship.

The application allows users to create, edit, complete and delete tasks while automatically saving their tasks in the browser.

## Features

- Add new tasks
- Mark tasks as completed
- Move completed tasks to a separate section
- Inline task editing
- Delete tasks
- Pending task count
- Completed task count
- Total task count
- Timestamp for task creation
- LocalStorage persistence
- Empty states
- Enter key support for adding tasks
- Responsive design
- Mobile-friendly interface
- Clean and professional UI

## Technologies Used

- HTML5
- CSS3
- JavaScript
- CSS Flexbox
- CSS Grid
- Browser LocalStorage API

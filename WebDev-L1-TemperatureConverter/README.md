# Tempora — Temperature Converter

A modern, responsive temperature conversion web application built as part of the Oasis Infobyte AICTE Internship Program.

The application allows users to convert temperatures between Celsius, Fahrenheit and Kelvin with accurate results and input validation.

## 🚀 Features

- Celsius, Fahrenheit and Kelvin input units
- Convert temperature instantly
- Displays all three converted values
- Numeric input validation
- Empty input validation
- Absolute zero validation
- Supports decimal temperatures
- Press Enter to convert
- Clean and responsive interface
- Mobile-friendly design
- Modern dark-themed UI
- Responsive CSS Grid and Flexbox layout

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- CSS Grid
- CSS Flexbox
- Google Fonts

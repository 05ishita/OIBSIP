# Calcura — Smart Calculator

A modern and responsive calculator web application built as part of the Oasis Infobyte AICTE Internship Program.

## 🚀 Features

- Addition
- Subtraction
- Multiplication
- Division
- Percentage/remainder operation
- Decimal calculations
- Clear (AC)
- Backspace/Delete
- Current input and result display
- Operator chaining
- Division-by-zero error handling
- Keyboard support
- Responsive design
- CSS Grid keypad
- Event listeners instead of inline onclick handlers
- No `eval()` used

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- CSS Grid
- Responsive Web Design
- Google Fonts

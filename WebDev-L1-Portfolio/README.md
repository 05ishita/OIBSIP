# Ishita Singh — Personal Portfolio

A modern, responsive personal portfolio website showcasing my skills, projects, and contact information as a Full Stack Developer.

## 🚀 Features

- Responsive navigation bar
- Hero section with professional profile photo
- Developer role and introduction
- About Me section
- Skills showcase
- Frontend, Backend, Database and Tools categories
- Selected projects section
- Project descriptions and technology tags
- GitHub project links
- Contact section
- Email and social links
- Smooth scrolling navigation
- Fully responsive design for desktop, tablet and mobile
- Modern dark-themed professional UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- CSS Flexbox
- CSS Grid
- Google Fonts
- Responsive Web Design
